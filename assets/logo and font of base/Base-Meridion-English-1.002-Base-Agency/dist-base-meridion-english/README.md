# Base Meridion English 1.002

Base Meridion English is a Base-named OFL derivative built from Inter 4.1, chosen as a lawful high-quality neutral sans source. It is not copied from, renamed from, or traced from Graphik.

Arabic-script Unicode ranges are intentionally mapped to period-dot glyphs, so Arabic/Kurdish-Arabic text displays as dots.
